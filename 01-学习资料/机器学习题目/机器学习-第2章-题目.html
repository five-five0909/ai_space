第 2 章　机器学习基本理论

任何机器学习问题，不管表面上看起来多复杂，都可以用三个问题来拆解：

  • 学什么？（模型：用什么样的函数族来表达从输入到输出的映射）
  • 用什么标准评价好坏？（策略：定义"什么叫学得好"的损失/目标函数）
  • 怎么找到最优解？（算法：如何高效地在模型空间中搜索最优参数）
先建立一个总感觉：三要素就像"选手 + 裁判 + 赛制"

模型是参赛选手——它的能力范围决定了它能解决什么问题（一个线性模型就像只能走直线的运动员）；
策略是裁判规则——损失函数告诉模型"你现在答得有多差"，没有裁判就不知道怎么进步；
算法是训练赛制——梯度下降就像每天按教练指导改进动作，直到找到最佳状态。
三者缺一不可：再好的选手没有裁判规则不知道往哪里努力，再好的赛制没有合适的选手也无从发挥。

Q2-01　机器学习三要素：模型、策略、算法

题目描述：
机器学习方法 = 模型 + 策略 + 算法。三者共同构成了一个完整的机器学习系统。

问题：

  1. 用一句话定义三要素，并填写下表：
    要素核心问题具体内容举例数学表示
    模型用什么函数来表示从输入到输出的映射？假设空间 $\mathcal{F}$
    策略均方误差、交叉熵、对数损失
    算法如何求解使策略最优的模型参数？参数更新规则
  2. 以线性回归为例，具体说明三要素各是什么：
    1. 模型：函数族是什么形式？
    2. 策略：用什么损失函数？写出公式。
    3. 算法：可以用哪两种方法求解最优参数？
  3. "假设空间"（Hypothesis Space）是什么概念？它的大小对模型能力有什么影响？假设空间过大和过小分别有什么风险？
  4. 经验风险（Empirical Risk）和期望风险（Expected Risk）有什么区别？为什么最小化经验风险不等同于最小化期望风险？

来源溯源：[文档第 2 章 2.1 机器学习三要素]

小白必读：损失函数和目标函数是同一个东西吗？
  • 损失函数（Loss Function）：衡量单个样本预测值与真实值之间差距的函数，如 $L(\hat{y}, y) = (\hat{y} - y)^2$。
  • 代价函数（Cost Function）：通常指整个训练集的平均损失，$J(\theta) = \frac{1}{n}\sum_i L(\hat{y}_i, y_i)$，是优化的直接对象。
  • 目标函数（Objective Function）：最广义的叫法，可以包含正则化项等，$\text{Obj}(\theta) = J(\theta) + \lambda R(\theta)$。
  • 三者在很多语境下混用，但严格来说粒度不同：损失函数是样本级，代价函数是数据集级，目标函数是优化级。
参考答案与详细解析

(1) 三要素填表：

要素核心问题具体内容举例数学表示
模型用什么函数映射输入到输出？线性模型、决策树、神经网络假设空间 $\mathcal{F}$
策略用什么标准衡量模型好坏？均方误差、交叉熵损失/目标函数 $L$
算法如何高效求最优参数？梯度下降、牛顿法、解析解参数更新规则

(2) 线性回归的三要素：

  1. 模型：$f(x) = w^T x + b$，线性函数族，假设空间为所有可能的权重向量 $w$ 和偏置 $b$。
  2. 策略：均方误差（MSE）：$L(w,b) = \dfrac{1}{n}\sum_{i=1}^n (f(x_i) - y_i)^2$
  3. 算法：解析解（正规方程 $w^* = (X^TX)^{-1}X^Ty$）或梯度下降法（迭代更新 $w \leftarrow w - \eta\nabla_w L$）。

(3) 假设空间：

假设空间是模型候选函数的集合——即"我们假设真实映射落在哪类函数中"。假设空间越大，模型表达能力越强，但过大会导致过拟合（过多候选函数，容易找到"记住训练数据"但不泛化的解）；假设空间过小，则表达能力不足，导致欠拟合（真实映射不在假设空间内，怎么优化都学不好）。

(4) 经验风险 vs 期望风险：

两种风险的本质区别

期望风险（真正想最小化）：模型在所有可能数据上的平均损失，$R_{\exp}(f) = E_{(x,y)\sim P}[L(f(x), y)]$，依赖未知的真实数据分布 $P$，无法直接计算。
经验风险（实际优化对象）：模型在有限训练集上的平均损失，$R_{\text{emp}}(f) = \frac{1}{n}\sum_i L(f(x_i), y_i)$，可以计算。
当训练数据量有限时，经验风险只是期望风险的一个估计，存在偏差——训练集可能有偏，或模型过拟合训练集后经验风险很低但期望风险很高。这就是为什么需要测试集来估计真实泛化误差。

Q2-02　机器学习方法分类：监督/无监督/强化 + 生成/判别

题目描述：
机器学习方法从不同维度可以分成多种类型，两个最重要的分类维度是：①是否有标签（监督/无监督/强化），②建模目标（生成模型 vs 判别模型）。

问题：

  1. 填写下表，对比监督学习、无监督学习、半监督学习、强化学习：
    类型训练数据学习目标典型算法
    监督学习学习 $f: x\to y$
    无监督学习K-means、PCA
    半监督学习
    强化学习学习最优决策策略
  2. 生成模型（Generative Model）vs 判别模型（Discriminative Model）：
    1. 两者建模的目标概率分布分别是什么？（用 $P(y|x)$ 和 $P(x,y)$ 表示）
    2. 朴素贝叶斯属于哪类？逻辑回归属于哪类？SVM 属于哪类？
    3. 生成模型有什么额外能力是判别模型不具备的？
  3. 以下哪些描述正确？（多选，并解释错误选项的错误之处）
    1. 深度学习一定属于监督学习
    2. 强化学习不需要任何数据，只靠与环境交互
    3. 无监督学习不能用于分类任务
    4. 半监督学习通常在有标签数据少、无标签数据多时使用
    5. 所有监督学习都需要大量标注数据才能工作

来源溯源：[文档第 2 章 2.2 机器学习方法分类]

参考答案与详细解析

(1) 方法分类对比：

类型训练数据学习目标典型算法
监督学习带标签 $\{(x_i,y_i)\}$学习 $f:x\to y$线性回归、SVM、神经网络
无监督学习无标签 $\{x_i\}$发现数据内在结构K-means、PCA、DBSCAN
半监督学习少量有标签 + 大量无标签利用无标签数据辅助监督学习Label Propagation、自训练
强化学习环境交互的奖励信号学习最优决策策略Q-learning、PPO、AlphaGo

(2) 生成模型 vs 判别模型：

  1. 生成模型建模联合分布 $P(x, y)$（或类条件分布 $P(x|y)$），通过贝叶斯定理推导 $P(y|x)$；判别模型直接建模条件分布 $P(y|x)$。
  2. 朴素贝叶斯→生成模型；逻辑回归→判别模型；SVM→判别模型（直接找分界面）。
  3. 生成模型因为建模了 $P(x)$，可以生成新样本（如 GAN、VAE 生成图片）；还可以处理缺失数据（利用联合分布填补），以及异常检测（低概率 $P(x)$ 的样本是异常）。判别模型只能做分类/回归，不具备这些能力。

(3) 正确/错误分析：

  • A——错误：深度学习可以是无监督（如自编码器）、半监督（如对比学习）或强化学习（如 DQN），不仅限于监督学习。
  • B——部分正确但表述不精确：强化学习不需要预先标注的数据集，但其"经验数据"来自智能体与环境的交互（奖励信号本身就是一种反馈数据）。
  • C——错误：无监督学习可以辅助分类——先聚类，再给每个簇打标签，这是一种"先无监督后有监督"的半流程。
  • D——正确：半监督学习正是为"标注稀缺"场景设计的。
  • E——错误：Few-shot learning、零样本学习等方法可以用极少量标注数据完成分类任务。
Q2-03　建模流程：从数据到部署的完整 Pipeline

题目描述：
一个完整的机器学习项目不只是"跑一个模型"，而是包含多个有严格顺序要求的步骤。

问题：

  1. 将下列步骤按正确顺序排列，并简要说明每步的目的：

    （乱序列表）模型部署与监控 / 数据收集与清洗 / 模型训练 / 问题定义 / 特征工程 / 模型评估与选择 / 数据集划分 / 超参数调优

  2. "数据集划分"步骤中，通常将数据分为训练集、验证集、测试集三部分。
    1. 三者各自的作用是什么？
    2. 为什么不能用测试集来调参？用测试集调参会导致什么问题？
    3. 典型的三部分比例是多少？（如 70/15/15 等，可以有多种合理答案）
  3. 特征工程在整个流程中处于什么位置？它的主要工作内容有哪些？（列举 3 个以上）
  4. 为什么说"垃圾进，垃圾出"（Garbage In, Garbage Out）？数据质量对最终模型有什么决定性影响？

来源溯源：[文档第 2 章 2.3 建模流程]

参考答案与详细解析

(1) 正确顺序：

①问题定义 → ②数据收集与清洗 → ③数据集划分 → ④特征工程 → ⑤模型训练 → ⑥模型评估与选择 → ⑦超参数调优 → ⑧模型部署与监控

各步目的：

  • 问题定义：明确任务类型（分类/回归？）、评估指标、约束条件（延迟要求、可解释性需求）。
  • 数据收集与清洗：获取原始数据，处理缺失值、异常值、重复数据，保证数据质量。
  • 数据集划分：在任何特征处理之前先划分，防止信息泄漏。
  • 特征工程：在训练集上 fit 变换器，对训练/验证/测试集做 transform，提取有效特征。
  • 模型训练：用训练集拟合模型参数。
  • 模型评估与选择：用验证集比较不同模型的性能，选出最佳候选。
  • 超参数调优：用网格搜索/贝叶斯优化等方法在验证集上调整超参数。
  • 部署与监控：将模型上线服务，持续监控线上性能（数据漂移检测）。

(2) 数据集划分：

  1. 训练集：拟合模型参数；验证集：调整超参数、进行模型选择；测试集：最终评估，模拟真实部署效果，只用一次。
  2. 用测试集调参相当于将测试集变成了"另一个验证集"，模型间接地"见过"测试集，导致对真实泛化能力的估计偏乐观（信息泄漏/数据泄露）。
  3. 典型比例：数据量大时 80/10/10 或 70/15/15；数据量小时可用 k 折交叉验证替代固定验证集。

(3) 特征工程位置与内容：

特征工程在数据划分之后、模型训练之前进行（且必须先在训练集上 fit，再 transform 所有集合，防止测试集信息泄漏）。主要内容：缺失值填充、异常值处理、归一化/标准化、类别编码（One-hot/Label Encoding）、特征选择（过滤/包裹/嵌入法）、特征构造（交叉特征、多项式特征）、降维（PCA）。

(4) "Garbage In, Garbage Out"：

模型只能从数据中学习存在的模式，数据本身的偏差（噪声、错误标注、采样偏差）会被模型"学进去"并放大。再好的算法也无法从错误数据中学到正确规律。实践中数据清洗和特征工程通常占据整个项目 60--80% 的时间，是决定最终效果的最关键环节。

Q2-04　综合应用：识别三要素，规划建模流程

题目描述：
某互联网公司想构建一个模型，根据用户在 App 上的行为数据（浏览时长、点击次数、搜索关键词数量、设备类型等 20 个特征），预测用户次日是否会流失（不再使用 App）。历史数据有 50 万条记录，其中已有人工标注的"是否流失"标签，流失率约为 5%。

问题：

  1. 识别该任务的三要素：
    1. 模型：可以选用哪类模型？（至少列出两种候选）
    2. 策略：适合用什么损失函数？（注意：流失率只有 5%，类别极不平衡）
    3. 算法：如果选用逻辑回归，求解参数的算法是什么？
  2. 该任务属于哪种机器学习类型？（监督/无监督/强化，分类/回归？）
  3. 5% 的流失率意味着数据严重类别不平衡。列出至少两种处理不平衡数据的策略。
  4. 规划完整的建模流程（列出关键步骤，每步一句话说明）。
  5. 如果公司同时有另一批没有流失标注的用户行为数据（500 万条），是否可以利用起来？如何利用？

来源溯源：[文档第 2 章 2.1--2.3]

参考答案与详细解析

(1) 三要素识别：

  1. 模型候选：逻辑回归（可解释性好，适合初期基线）；XGBoost/随机森林（处理非线性关系，效果通常更好）；深度神经网络（数据量足够时可以尝试）。
  2. 策略：基础可用对数损失（交叉熵），但针对类别不平衡应使用加权交叉熵（给少数类流失样本更高权重），或使用 Focal Loss 重点关注难分类样本。评估指标推荐 AUC-ROC 或 F1 分数（准确率在不平衡时会误导）。
  3. 算法：逻辑回归使用梯度下降法（或 L-BFGS 拟牛顿法）最小化对数损失。

(2) 任务类型：监督学习——二分类（有标签，输出"是否流失"两个类别）。

(3) 处理类别不平衡的策略：

  • 过采样：对少数类（流失用户）进行重复采样或合成新样本（SMOTE 算法）；
  • 欠采样：对多数类（未流失用户）随机删除部分样本，使类别比例接近平衡；
  • 代价敏感学习：设置 class_weight='balanced' 参数，给少数类赋予更高的误分类代价；
  • 选择合适的评估指标：放弃准确率，改用 F1、AUC-ROC、PR 曲线下面积。

(4) 完整建模流程：

①问题定义（预测流失，评估指标选 AUC）→ ②数据探索与清洗（处理缺失值、异常行为）→ ③数据集划分（按时间切分，避免未来数据泄漏）→ ④特征工程（行为特征标准化，构造趋势特征）→ ⑤处理不平衡（SMOTE 过采样）→ ⑥模型训练（从逻辑回归基线开始）→ ⑦验证集调参（网格搜索超参数）→ ⑧测试集最终评估（一次性报告 AUC）→ ⑨部署与监控（监控模型分数分布，检测数据漂移）。

(5) 利用无标注数据：

可以采用半监督学习策略：用 50 万有标注数据训练初始模型，用该模型对 500 万无标注数据打伪标签（高置信度的预测），将伪标签数据加入训练集重新训练（自训练/Self-training）。还可以用无标注数据预训练特征提取器（如用无监督方法学习行为序列的嵌入表示），再用有标注数据微调分类头。

本章小结

  • 三要素框架：任何 ML 问题 = 模型（学什么）+ 策略（评价标准）+ 算法（怎么优化），三者明确后问题就被结构化了。
  • 方法分类的两个维度：有无标签（监督/无监督/强化）× 建模目标（生成/判别），四象限定位解决方案。
  • 建模流程的顺序很重要：数据划分必须在特征工程之前；测试集只用一次；超参数调优用验证集而非测试集。
  • 数据质量决定上限：再好的算法无法从差数据中学到好模型，数据清洗值得投入大量精力。
