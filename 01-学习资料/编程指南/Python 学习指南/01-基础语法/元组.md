# 元组 (Tuple)

元组是**不可变**的有序序列，一旦创建就不能修改。

## 创建元组

```python
# 基本创建
point = (3, 4)
single = (1,)  # 单元素元组需要逗号
empty = ()

# 不使用括号（可选）
coord = 1, 2, 3
```

> **提示**：单元素元组必须加逗号 `(1,)`，否则 `(1)` 只是带括号的整数。

## 访问元素

```python
t = ('a', 'b', 'c', 'd', 'e')

# 索引访问
print(t[0])    # 'a'
print(t[-1])   # 'e'

# 切片
print(t[1:3])  # ('b', 'c')

# 不可修改（会报错）
# t[0] = 'x'  # TypeError: 'tuple' object does not support item assignment
```

## 元组的特性

### 不可变性

```python
t = (1, 2, 3)
# t[0] = 100  # TypeError! 不能修改
```

> **提示**：元组本身不可变，但如果包含可变对象（如列表），该对象内部可以修改：
```python
t = ([1, 2], 3)
t[0].append(3)  # OK! 修改的是列表，不是元组
print(t)        # ([1, 2, 3], 3)
```

## LeetCode 实战场景

### 1. 函数返回多个值

```python
# LC 常见：同时返回索引
def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return (seen[complement], i)  # 返回元组
        seen[num] = i
    return (-1, -1)

# 解包接收
idx1, idx2 = two_sum([2, 7, 11, 15], 9)
```

### 2. BFS/DFS 中的 visited 集合

```python
# 网格问题中，用元组存储坐标（因为元组可哈希）
def bfs(grid, start, end):
    from collections import deque

    rows, cols = len(grid), len(grid[0])
    visited = set()
    visited.add(start)  # start 是 (row, col) 元组

    queue = deque([(start, 0)])  # ((row, col), distance)

    while queue:
        (r, c), dist = queue.popleft()

        for dr, dc in [(0,1), (0,-1), (1,0), (-1,0)]:  # 方向元组
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and (nr, nc) not in visited:
                visited.add((nr, nc))  # 元组可作为 set 元素
                queue.append(((nr, nc), dist + 1))

    return -1
```

> **提示**：元组可哈希（hashable），可以作为字典 key 和 set 元素；列表不可哈希。

### 3. 动态规划中的状态表示

```python
# 多维 DP 状态常用元组
def min_path_sum(grid):
    memo = {}

    def dp(i, j):
        if (i, j) in memo:
            return memo[(i, j)]
        if i == 0 and j == 0:
            return grid[0][0]
        if i < 0 or j < 0:
            return float('inf')

        memo[(i, j)] = grid[i][j] + min(dp(i-1, j), dp(i, j-1))
        return memo[(i, j)]

    return dp(len(grid)-1, len(grid[0])-1)
```

### 4. 排序时的复合键

```python
# LC 常见：多关键字排序
tasks = [(1, 'A'), (3, 'B'), (1, 'C'), (2, 'A')]
# 先按优先级升序，再按字母升序
tasks.sort(key=lambda x: (x[0], x[1]))  # 使用元组作为排序键
```

### 2. 超参数配置（不可变）

```python
from dataclasses import dataclass

@dataclass(frozen=True)  # frozen=True 使配置不可变
class TrainingConfig:
    learning_rate: float = 1e-4

config = TrainingConfig()
```

```python
class CustomDataset(Dataset):
```

## 元组 vs 列表

| 特性 | 元组 (tuple) | 列表 (list) |
|------|--------------|-------------|
| 可变性 | 不可变 | 可变 |
| 性能 | 略快 | 略慢 |
| 可哈希 | ✅ 可作为 dict key | ❌ 不能 |
| 用途 | 固定数据、返回值、字典 key | 可变集合、栈、队列 |

## 常用元组操作

```python
t = (1, 2, 3)

# 基本操作
len(t)           # 3
t + (4, 5)       # (1, 2, 3, 4, 5)
t * 2            # (1, 2, 3, 1, 2, 3)
1 in t           # True

# 解包
a, b, c = t
a, *rest = t     # a=1, rest=[2,3]

# 交换变量
a, b = b, a      # Pythonic 交换

# 计数和查找
t.count(2)       # 出现次数
t.index(2)       # 第一次出现的索引
```

## 命名元组 (NamedTuple)

```python
from collections import namedtuple

# 定义命名元组
Point = namedtuple('Point', ['x', 'y'])
p = Point(3, 4)

print(p.x)      # 3 - 按名称访问
print(p[0])     # 3 - 也可按索引访问
print(p._asdict())  # OrderedDict([('x', 3), ('y', 4)])
```

> **提示**：NamedTuple 比普通元组更可读，适合表示结构化数据（如配置、记录）。

## 性能提示

> **时间复杂度**：
> - 索引访问：O(1)
> - 查找（in）：O(n)
> - 哈希（作为 dict key）：O(1) 平均

> **内存**：元组比列表占用更少内存，因为不需要预分配额外空间。
