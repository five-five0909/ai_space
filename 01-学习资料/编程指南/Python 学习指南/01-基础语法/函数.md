## 参数类型

### 位置参数 + 默认参数

```python
def power(base, exp=2):
    return base ** exp

power(3)      # 9
power(3, 3)   # 27
```

> **提示**：默认参数必须在位置参数之后；**不要使用可变对象作为默认参数**。

```python
# 错误示例
def bad_func(item, items=[]):  # ❌ 列表只创建一次，多次调用共享
    items.append(item)
    return items

# 正确示例
def good_func(item, items=None):  # ✅ 每次调用都是新列表
    if items is None:
        items = []
    items.append(item)
    return items
```

### *args 和 **kwargs

```python
def flexible_func(a, b, *args, **kwargs):
    """
    a, b: 位置参数
    *args: 额外位置参数（元组）
    **kwargs: 关键字参数（字典）
    """
    print(f"args={args}")      # 元组
    print(f"kwargs={kwargs}")  # 字典
```

def timer(func):

    @wraps(func)

        result = func(*args, **kwargs)
        end = time.perf_counter()
        print(f"{func.__name__} 耗时：{end - start:.6f} 秒")

    return wrapper

### 2. LRU Cache 用于记忆化搜索（递归 DP）

```python
from functools import lru_cache

# LC 经典：爬楼梯
@lru_cache(maxsize=None)
def climb_stairs(n):
    if n <= 2:
        return n
    return climb_stairs(n-1) + climb_stairs(n-2)

# LC 经典：不同路径
@lru_cache(maxsize=None)
def unique_paths(m, n):
    if m == 1 or n == 1:
        return 1
    return unique_paths(m-1, n) + unique_paths(m, n-1)
```

> **提示**：`@lru_cache` 要求参数必须是可哈希的，所以列表要转成元组。

### 3. 回溯算法模板

```python
def permute(nums):
    """LC 46: 全排列"""
    results = []

    def backtrack(path):
        if len(path) == len(nums):
            results.append(path[:])
            return
        for num in nums:
            if num not in path:
                path.append(num)
                backtrack(path)
                path.pop()

    backtrack([])
    return results
```

### 4. 滑动窗口模板

```python
def sliding_window_template(s, condition_func):
    left = 0
    window_state = {}
    result = 0

    for right in range(len(s)):
        window_state[s[right]] = window_state.get(s[right], 0) + 1

        while not condition_func(window_state):
            window_state[s[left]] -= 1
            if window_state[s[left]] == 0:
                del window_state[s[left]]
            left += 1

        result = max(result, right - left + 1)

    return result
```

## 科研实战场景

### 1. 训练函数封装（使用*args/**kwargs）

```python
import torch

def train_one_epoch(model, dataloader, optimizer, criterion, device, **kwargs):
    """
    训练一个 epoch

    Args:
        model: PyTorch 模型
        dataloader: 数据加载器
        optimizer: 优化器
        criterion: 损失函数
        device: 设备 (cuda/cpu)
        **kwargs: 额外参数（如 epoch、log_interval 等）
    """
    model.train()
    total_loss = 0
    epoch = kwargs.get('epoch', 0)
    log_interval = kwargs.get('log_interval', 10)

    for batch_idx, (data, target) in enumerate(dataloader):
        data, target = data.to(device), target.to(device)

        optimizer.zero_grad()
        output = model(data)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()

        total_loss += loss.item()

        if batch_idx % log_interval == 0:
            print(f"Epoch {epoch}, Batch {batch_idx}, Loss: {loss.item():.4f}")

    return total_loss / len(dataloader)
```

### 2. 装饰器用于实验日志

```python
from functools import wraps
import logging
from datetime import datetime

def log_experiment(log_file="experiment.log"):
    """记录实验日志的装饰器"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            logging.basicConfig(
                filename=log_file,
                level=logging.INFO,
                format='%(asctime)s - %(levelname)s - %(message)s'
            )
            logging.info(f"开始实验：{func.__name__}")
            start_time = datetime.now()
            try:
                result = func(*args, **kwargs)
                logging.info(f"实验成功")
                return result
            except Exception as e:
                logging.error(f"实验失败：{str(e)}", exc_info=True)
                raise
            finally:
                duration = datetime.now() - start_time
                logging.info(f"实验耗时：{duration}")
        return wrapper
    return decorator

@log_experiment()
def run_training(config):
    # 训练代码
    pass
```

## 高阶函数

### sorted 与 key 函数

```python
# LC 常见：按绝对值排序
nums = [-3, 1, -2, 5, 0]
sorted_by_abs = sorted(nums, key=abs)  # [0, 1, -2, -3, 5]

# 多关键字排序
students = [('Alice', 85), ('Bob', 75), ('Charlie', 90)]
sorted_by_score = sorted(students, key=lambda x: x[1])
```

## lambda 表达式

```python
add = lambda x, y: x + y
pairs = [(1, 3), (4, 1), (2, 2)]
pairs.sort(key=lambda x: x[1])  # 按第二个元素排序
```

> **提示**：lambda 只能包含一个表达式，复杂逻辑还是用 `def`。

## 性能提示

> **优化建议**：
> - 频繁调用的函数使用 `@lru_cache` 缓存结果
> - 避免在循环中定义函数（每次迭代都会创建新函数对象）
> - 使用局部变量代替全局变量（查找更快）
