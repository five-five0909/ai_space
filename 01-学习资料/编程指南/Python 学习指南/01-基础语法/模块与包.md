# 模块与包 (Module & Package)

## 模块基础

模块就是一个 `.py` 文件，用于组织代码。

```python
# math_utils.py
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

# 使用
import math_utils
result = math_utils.add(3, 5)

from math_utils import add
result = add(3, 5)
```

## 导入方式

### 绝对导入 vs 相对导入

```python
# 项目结构
my_project/
├── main.py
├── utils/
│   ├── __init__.py
│   ├── helpers.py
│   └── data_loader.py
└── models/
    ├── __init__.py
    └── neural_net.py
```

```python
# 绝对导入（推荐）
from utils.helpers import process_data
from models.neural_net import NeuralNetwork

# 相对导入（只能在包内部使用）
from .helpers import process_data      # 当前目录
from ..utils import something          # 上一级目录
```

> **提示**：科研项目中优先使用**绝对导入**，代码更清晰，重构更容易。

```python
# utils/heap.py
import heapq

def kth_largest(nums, k):
    """使用堆找第 K 大元素"""
    heap = []
    for num in nums:
        if len(heap) < k:
            heapq.heappush(heap, num)
        elif num > heap[0]:
            heapq.heapreplace(heap, num)
    return heap[0]
```

### 2. 算法模板库

```python
# algorithms/search.py
def binary_search(nums, target):
    """二分查找标准实现"""
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

def binary_search_left(nums, target):
    """查找第一个 >= target 的位置"""
    left, right = 0, len(nums) - 1
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left
```

```python
# algorithms/graph.py
from collections import deque, defaultdict

def bfs(graph, start):
    """BFS 遍历"""
    visited = set()
    queue = deque([start])
    visited.add(start)

    while queue:
        node = queue.popleft()
        yield node
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

def dfs(graph, start):
    """DFS 遍历（迭代版）"""
    visited = set()
    stack = [start]

    while stack:
        node = stack.pop()
        if node not in visited:
            visited.add(node)
            yield node
            stack.extend(reversed(graph[node]))
```

### 2. 配置文件模块

```python
# config/settings.py
from pathlib import Path
from dataclasses import dataclass, field

@dataclass
class DataConfig:
    data_dir: Path = Path("data")
    batch_size: int = 32
    num_workers: int = 4

@dataclass
class ModelConfig:
    model_name: str = "resnet50"
    pretrained: bool = True
    num_classes: int = 10

@dataclass
class TrainingConfig:
    epochs: int = 100
    learning_rate: float = 1e-4
    weight_decay: float = 1e-5

@dataclass
class Config:
    data: DataConfig = field(default_factory=DataConfig)
    model: ModelConfig = field(default_factory=ModelConfig)
    training: TrainingConfig = field(default_factory=TrainingConfig)
    device: str = "cuda"
    seed: int = 42
    log_dir: Path = Path("logs")
    checkpoint_dir: Path = Path("checkpoints")
```

### 3. 模块化的训练流程

```python
# main.py
from config.settings import Config
from models.resnet import ResNet50
from training.trainer import Trainer

def main():
    config = Config()
    model = ResNet50(num_classes=config.model.num_classes)
    trainer = Trainer(model, config)

    for epoch in range(config.training.epochs):
        trainer.train_epoch()
        trainer.validate()

if __name__ == "__main__":
    main()
```

## 性能提示

> **导入优化**：
> - 模块只导入一次（导入后被缓存）
> - 避免循环导入（A 导入 B，B 导入 A）

> **最佳实践**：
> - 导入顺序：标准库 → 第三方库 → 本地模块
> - 避免 `from module import *`（污染命名空间）
