### 1. 反转字符串 (LC 344)

```python
def reverse_string(s: str) -> str:
    """反转字符串"""
    return s[::-1]

# 或者原地反转（列表）
def reverse_inplace(s: list):
    left, right = 0, len(s) - 1
    while left < right:
        s[left], s[right] = s[right], s[left]
        left += 1
        right -= 1
```

### 2. 验证回文串 (LC 125)

```python
def is_palindrome(s: str) -> bool:
    """验证回文串，忽略非字母数字"""
    cleaned = ''.join(c.lower() for c in s if c.isalnum())
    return cleaned == cleaned[::-1]
```

### 3. 字符串压缩 (LC 443)

```python
def compress_string(s: str) -> str:
    """字符串压缩：aaabbbccc -> a3b3c3"""
    if not s:
        return ""

    result = []
    count = 1
    for i in range(1, len(s)):
        if s[i] == s[i-1]:
            count += 1
        else:
            result.append(s[i-1] + str(count))
            count = 1
    result.append(s[-1] + str(count))

    compressed = ''.join(result)
    return compressed if len(compressed) < len(s) else s
```

### 4. 无重复字符的最长子串 (LC 3)

```python
def length_of_longest_substring(s: str) -> int:
    """滑动窗口"""
    char_set = set()
    left = 0
    max_len = 0

    for right in range(len(s)):
        while s[right] in char_set:
            char_set.remove(s[left])
            left += 1
        char_set.add(s[right])
        max_len = max(max_len, right - left + 1)

    return max_len
```

### 5. 找不同 (LC 389)

**题目**：字符串 t 由 s 随机重排后添加一个字母生成，找出 t 中多出的那个字符。

**方法一：求和相减**

```python
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        # t 比 s 多一个字符，把所有字符转成 ASCII 码求和
        # 两者之差就是多出来那个字符的 ASCII 码
        return chr(sum(ord(c) for c in t) - sum(ord(c) for c in s))
```

**方法二：异或（推荐）**

```python
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        res = 0
        # 把 s 和 t 所有字符的 ASCII 码依次异或
        # 相同字符会两两抵消（a ^ a == 0）
        # 最后剩下的就是 t 里多出来那个字符的 ASCII 码
        for c in s + t:
            res ^= ord(c)
        # 将 ASCII 码转回字符
        return chr(res)
```

> **提示**：异或法更优雅，且不会溢出（虽然 Python 整数不会溢出，但其他语言要考虑）。

import re

def parse_training_log(log_line: str) -> dict:
    """解析训练日志行"""
    # Epoch [1/10], Loss: 0.2345, Acc: 0.8765
    pattern = r'Epoch \[(\d+)/(\d+)\], Loss: ([\d.]+), Acc: ([\d.]+)'
    match = re.match(pattern, log_line)
    if match:
        return {
            'epoch': int(match.group(1)),

            'accuracy': float(match.group(4))
        }

## 原子知识点拆分

### 字符串乘法 `*`

```python
# 字符串重复 n 次
"a" * 3       # "aaa"
"ab" * 2      # "abab"
"hello" * 0   # "" （空字符串）

# 实际应用：生成重复模式
"-" * 10      # "----------" （分隔线）
"\n" * 3      # "\n\n\n" （多个换行）
```

> **原理**：`str * n` 返回字符串重复 n 次的结果，n 必须是整数。

### 整除运算符 `//`

```python
# 向下取整除法
7 // 3        # 2 （不是 2.33）
10 // 3       # 3
-7 // 3       # -3 （注意：向下取整，不是 -2）

# 与普通除法的区别
7 / 3         # 2.333... （浮点数）
7 // 3        # 2 （整数）

# 常见用途：计算能分成多少份
len(s) // len(sub)  # 字符串 s 能分成多少个 sub
```

> **注意**：负数整除时向下取整，如 `-7 // 3 = -3`（不是 -2）。

### 字符串相等比较 `==`

```python
# 字符串内容比较
"abc" == "abc"    # True
"abc" == "ABC"    # False （区分大小写）

# 与 is 的区别
a = "hello"
b = "hello"
a == b            # True （内容相同）
a is b            # True （短字符串有缓存，实际同一对象）

a = "hello world!"
b = "hello world!"
a == b            # True （内容相同）
a is b            # False （长字符串无缓存，不同对象）
```

> **最佳实践**：字符串比较用 `==`，不要用 `is`。

### 组合应用：重复子串模式检测

```python
# 检查字符串是否由重复子串构成
# 原理：如果 s 由 sub 重复 n 次构成，则 sub * n == s
def repeated_substring_pattern(s: str) -> bool:
    """LC 459: 重复子字符串模式"""
    n = len(s)
    # 遍历所有可能的子串长度 i（必须是 s 长度的因子）
    for i in range(1, n // 2 + 1):
        if n % i == 0:              # i 是 n 的因子
            sub_str = s[:i]         # 取前 i 个字符作为子串
            l = len(s)              # 原串长度
            if sub_str * (l // i) == s:
                return True
    return False

# 示例
repeated_substring_pattern("abab")     # True  ("ab" * 2)
repeated_substring_pattern("abcabc")   # True  ("abc" * 2)
repeated_substring_pattern("aba")      # False (无重复模式)
```

> **表达式拆解**：`sub_str * (l // i) == s`
> - `sub_str`：候选子字符串（如 "ab"）
> - `l // i`：重复次数（如 6 // 2 = 3）
> - `sub_str * (l // i)`：子串重复后的结果（如 "ab" * 3 = "ababab"）
> - `== s`：检查是否等于原字符串

## 原子知识点：三元表达式

### 基础三元表达式

```python
# 语法：value_if_true if condition else value_if_false

# 基础用法
x = 5
result = "正数" if x > 0 else "负数或零"  # "正数"

# 等价于
if x > 0:
    result = "正数"
else:
    result = "负数或零"
```

### 嵌套三元表达式

```python
# 嵌套用法：处理多层条件判断
x = 0
result = 0 if x == 0 else (-1 if x < 0 else 1)

# 等价于
if x == 0:
    result = 0
elif x < 0:
    result = -1
else:
    result = 1

# 实际案例：数组符号判断 (LC 1822)
class Solution:
    def arraySign(self, nums: List[int]) -> int:
        neg = sum(1 for x in nums if x < 0)
        return 0 if 0 in nums else (-1 if neg % 2 else 1)

# 拆解理解：
# 第一层：0 in nums ? → 有 0 就返回 0
# 第二层：neg % 2 == 1 ? → 负数个数为奇数就返回 -1
# 第三层：否则返回 1
```

> **阅读技巧**：从左往右读，遇到 `if` 就判断条件，条件为真取左边值，条件为假取右边值（右边可能又是另一个三元表达式）。

### 三元表达式 vs if-else 对照

| 缩写版（三元表达式） | 展开版（if-else） |
|---|---|
| `0 if 0 in nums else (-1 if neg % 2 else 1)` | 见下方展开代码 |

```python
# 展开版（更易理解）
class Solution:
    def arraySign(self, nums: List[int]) -> int:
        # 第一步：统计负数的个数
        negative_count = 0
        for x in nums:
            if x < 0:
                negative_count += 1
        
        # 第二步：只要有0，整体乘积就是0，直接返回
        for x in nums:
            if x == 0:
                return 0
        
        # 第三步：没有0的情况下
        # 负数个数是奇数 -> 乘积是负数 -> 返回 -1
        # 负数个数是偶数 -> 乘积是正数 -> 返回 1
        if negative_count % 2 == 1:
            return -1
        else:
            return 1
```

> **建议**：初学者先写展开版，理解逻辑后再用三元表达式简化。

## 原子知识点：生成器表达式

### 基础语法

```python
# 语法：(expression for item in iterable if condition)
# 注意：生成器表达式用圆括号，列表推导式用方括号

# 统计满足条件的元素个数
nums = [1, -2, 3, -4, 5]
neg_count = sum(1 for x in nums if x < 0)  # 2

# 等价于
neg_count = 0
for x in nums:
    if x < 0:
        neg_count += 1
```

### 生成器表达式 vs 列表推导式

```python
# 列表推导式：生成一个列表（占用内存）
[1 for x in nums if x < 0]  # [1, 1] - 实际存储了这个列表

# 生成器表达式：生成一个迭代器（惰性求值，不占内存）
(1 for x in nums if x < 0)  # 生成器对象，不存储数据

# 配合 sum() 使用时，生成器更高效
sum(1 for x in nums if x < 0)  # 推荐：内存友好
sum([1 for x in nums if x < 0])  # 不推荐：先创建列表再求和
```

### 常见用途

```python
# 1. 统计个数
neg = sum(1 for x in nums if x < 0)

# 2. 求和（带条件）
total = sum(x for x in nums if x > 0)  # 只统计正数的和

# 3. 检查是否存在（配合 any/all）
has_negative = any(x < 0 for x in nums)  # 是否有负数
all_positive = all(x > 0 for x in nums)  # 是否全是正数

# 4. 求最大/最小（带条件）
max_neg = max(x for x in nums if x < 0)  # 最大的负数
```

> **原理**：`sum(1 for x in nums if x < 0)` —— 每遇到一个负数就"贡献"一个 1，最后求和得到负数总数。

## 原子知识点：`in` 操作符

### 判断元素是否存在

```python
# 列表中判断元素是否存在
nums = [1, 2, 3, 0, -1]
0 in nums      # True
5 in nums      # False

# 字符串中判断子串是否存在
"ab" in "abc"    # True
"bd" in "abc"    # False

# 字典中判断键是否存在
d = {"a": 1, "b": 2}
"a" in d         # True（判断的是键，不是值）
1 in d           # False（值不在键中）
```

### 等价写法对照

```python
# 缩写版
return 0 if 0 in nums else 1

# 展开版
for x in nums:
    if x == 0:
        return 0
return 1
```

> **时间复杂度**：列表用 `in` 是 O(n)，字典/集合用 `in` 是 O(1)。

## 性能提示

> **时间复杂度**：
> - 索引访问：O(1)
> - 切片：O(k)，k 为切片长度
> - 连接（+）：O(n*m)，n 为字符串数，m 为平均长度
> - join：O(n)，推荐方式

> **最佳实践**：
> - 多字符串连接使用 `"".join(list)` 而非 `+`
> - 频繁修改字符串使用 `io.StringIO`
