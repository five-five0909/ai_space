# 日期时间处理

## datetime 基础

```python
from datetime import datetime, date, time, timedelta

# 当前时间
now = datetime.now()
today = date.today()

# 创建日期
dt = datetime(2024, 1, 15, 10, 30, 0)
d = date(2024, 1, 15)

# 格式化输出
dt.strftime("%Y-%m-%d %H:%M:%S")  # '2024-01-15 10:30:00'
dt.strftime("%Y/%m/%d")           # '2024/01/15'
```

## 解析字符串

```python
# 解析 ISO 格式
dt = datetime.fromisoformat("2024-01-15T10:30:00")

# 解析自定义格式
dt = datetime.strptime("2024-01-15", "%Y-%m-%d")
```

## 时间计算

```python
# 时间差
delta = timedelta(days=7, hours=2)
future = now + delta
past = now - timedelta(days=3)

# 计算相差天数
diff = future - now
print(diff.days)  # 7
```

## LeetCode 实战场景

### 1. 计算天数差 (LC 1360)

```python
from datetime import datetime

def days_between(date1: str, date2: str) -> int:
    """计算两个日期之间的天数"""
    fmt = "%Y-%m-%d"
    d1 = datetime.strptime(date1, fmt)
    d2 = datetime.strptime(date2, fmt)
    return abs((d2 - d1).days)
```

### 2. 判断闰年

```python
def is_leap_year(year: int) -> bool:
    """判断是否为闰年"""
    return (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)
```

### 3. 一周中的第几天

```python
from datetime import datetime

def day_of_week(date_str: str) -> str:
    """返回星期几"""
    days = ["Monday", "Tuesday", "Wednesday", "Thursday",
            "Friday", "Saturday", "Sunday"]
    dt = datetime.strptime(date_str, "%Y-%m-%d")
    return days[dt.weekday()]
```

## 科研实战场景

### 1. 实验时间戳

```python
from datetime import datetime

def generate_timestamp() -> str:
    """生成实验目录时间戳"""
    return datetime.now().strftime("%Y%m%d_%H%M%S")

# 输出：20240405_143052
```

### 2. 训练时间统计

```python
import time
from datetime import timedelta

def format_training_time(start_time: float, end_time: float) -> str:
    """格式化训练耗时"""
    total_seconds = int(end_time - start_time)
    return str(timedelta(seconds=total_seconds))

# 输出：1:23:45 (1 小时 23 分 45 秒)
```

### 3. 学习率调度时间

```python
from datetime import datetime, timedelta

def get_lr_schedule(start_time: datetime, epochs: int):
    """生成学习率调度时间表"""
    schedule = []
    current_lr = 1e-4

    for epoch in range(epochs):
        schedule.append({
            'epoch': epoch,
            'lr': current_lr,
            'timestamp': start_time + timedelta(hours=epoch * 2)  # 假设每 epoch 2 小时
        })
        if epoch > 50:
            current_lr *= 0.1

    return schedule
```

### 4. 实验日志时间戳

```python
def log_with_timestamp(message: str, level: str = "INFO"):
    """带时间戳的日志"""
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    print(f"[{timestamp}] [{level}] {message}")
```

## 时区处理

```python
from datetime import datetime, timezone, timedelta

# UTC 时间
utc_now = datetime.now(timezone.utc)

# 转换为东八区
cn_time = utc_now.astimezone(timezone(timedelta(hours=8)))

# 本地时间
local_now = datetime.now().astimezone()
```

## 易错点

### 1. 时区问题

```python
# naive datetime (无时区信息)
dt1 = datetime(2024, 1, 15)

# aware datetime (有时区信息)
dt2 = datetime(2024, 1, 15, tzinfo=timezone.utc)

# 不能直接比较
# dt1 < dt2  # TypeError!
```

### 2. 日期格式

```python
# %Y - 4 位年份 (2024)
# %y - 2 位年份 (24)
# %m - 月份 (01-12)
# %d - 日期 (01-31)
# %H - 小时 (00-23)
# %M - 分钟 (00-59)
# %S - 秒 (00-59)
```

## 性能提示

> datetime 操作通常很快，性能瓶颈多在 IO。

> **最佳实践**：
> - 存储时间使用 ISO 格式或时间戳
> - 跨时区应用使用 UTC 存储，显示时转换
> - 高精度计时使用 `time.perf_counter()`
