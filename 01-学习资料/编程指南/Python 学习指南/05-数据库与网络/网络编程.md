# 网络编程

## HTTP 请求 (requests 库)

```python
import requests

# GET 请求
response = requests.get("https://api.example.com/data")
print(response.status_code)
print(response.json())

# POST 请求
response = requests.post(
    "https://api.example.com/upload",
    json={"key": "value"},
    headers={"Authorization": "Bearer token"}
)

# 带超时
response = requests.get("https://api.example.com", timeout=5)

# 会话（保持连接）
session = requests.Session()
session.auth = ('user', 'pass')
r1 = session.get('https://api.example.com/1')
r2 = session.get('https://api.example.com/2')
```

## 科研实战场景

### 1. 下载预训练模型

```python
import requests
from tqdm import tqdm

def download_model(url: str, save_path: str):
    response = requests.get(url, stream=True)
    total = int(response.headers.get('content-length', 0))

    with open(save_path, 'wb') as f, tqdm(
        desc=save_path, total=total, unit='B', unit_scale=True
    ) as bar:
        for chunk in response.iter_content(chunk_size=8192):
            f.write(chunk)
            bar.update(len(chunk))
```

### 2. 调用 HuggingFace API

```python
def query_huggingface(model_id: str, text: str) -> dict:
    api_url = f"https://api-inference.huggingface.co/models/{model_id}"
    headers = {"Authorization": "Bearer YOUR_HF_TOKEN"}
    response = requests.post(api_url, headers=headers, json={"inputs": text})
    return response.json()
```

### 3. 爬取论文数据

```python
import requests
from bs4 import BeautifulSoup

def fetch_arxiv_papers(query: str, max_results: int = 10) -> list:
    base_url = "http://export.arxiv.org/api/query"
    params = {'search_query': query, 'max_results': max_results}
    response = requests.get(base_url, params=params)

    soup = BeautifulSoup(response.content, 'xml')
    papers = []
    for entry in soup.find_all('entry'):
        papers.append({
            'title': entry.title.text.strip(),
            'authors': [a.name.text for a in entry.find_all('author')],
            'url': entry.id.text
        })
    return papers
```

## 易错点

### 1. 忘记关闭连接
```python
# 正确：使用上下文管理器
with requests.get(url) as response:
    data = response.json()
```

### 2. 不处理超时
```python
# 正确：设置超时
response = requests.get(url, timeout=10)
```
