# Python 科研/AI 生态地图

> 快速查阅 Python 科研与深度学习常用技术栈

## 一、深度学习框架

| 领域 | 推荐方案 | 备选方案 | 说明 |
|------|----------|----------|------|
| **深度学习框架** | **PyTorch** | JAX, TensorFlow | 学术界主流，动态图易调试 |
| **高层封装** | **PyTorch Lightning** | timm, transformers | 简化训练循环，减少样板代码 |
| **模型库** | **HuggingFace Transformers** | timm, modelscope | 预训练模型中心，NLP/CV 全覆盖 |
| **分布式训练** | **DeepSpeed** | FSDP, Accelerate | 大模型训练必备，显存优化 |
| **模型编译** | **torch.compile** | ONNX, TensorRT | PyTorch 2.0+ 原生加速 |

## 二、实验管理

| 领域 | 推荐方案 | 备选方案 | 说明 |
|------|----------|----------|------|
| **实验追踪** | **wandb** | MLflow, TensorBoard | 可视化最佳，团队协作友好 |
| **配置管理** | **Hydra** | pydantic-settings, OmegaConf | 多配置组合，命令行覆盖 |
| **超参搜索** | **Optuna** | Ray Tune, wandb sweeps | 自动调参，支持多种采样器 |
| **实验复现** | **DVC** | Git LFS | 数据版本控制，管道管理 |

## 三、数据处理

| 领域 | 推荐方案 | 备选方案 | 说明 |
|------|----------|----------|------|
| **张量计算** | **NumPy** | PyTorch Tensor | 科学计算基础 |
| **数据框** | **Polars** | pandas, DuckDB | 比 pandas 快 10-100 倍 |
| **图像处理** | **Pillow** + **OpenCV** | torchvision.transforms, albumentations | 通用图像处理 |
| **数据增强** | **albumentations** | torchvision.transforms | 快速灵活的增强管道 |
| **音频处理** | **torchaudio** | librosa, soundfile | PyTorch 生态集成 |
| **文本处理** | **tokenizers** | tiktoken, sentencepiece | 快速分词器 |
| **数据集加载** | **datasets** (HuggingFace) | torchvision.datasets, webdataset | 大规模数据集流式加载 |

## 六、常用命令速查

```bash
# PyTorch 版本与 CUDA 检查
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"

# wandb 登录
wandb login

# Hydra 多配置运行
python train.py +experiment=baseline debug=true

# Optuna 调参
python tune.py --n_trials 100

# datasets 加载数据集
python -c "from datasets import load_dataset; ds = load_dataset('mnist')"

# uv 快速安装
uv pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```
