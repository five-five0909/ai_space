# Python 项目结构

> 推荐的项目结构与依赖管理

## 一、环境搭建

```bash
# 1. 安装 Python 3.11+（推荐 pyenv 管理版本）
# Windows: https://www.python.org/downloads/
# Mac/Linux:
curl https://pyenv.run | bash
pyenv install 3.12
```

## 四、数据管理规范

| 目录 | 用途 | 版本控制 |
|------|------|----------|
| `data/raw/` | 原始数据，只读 | `.gitignore` |
| `data/processed/` | 预处理数据 | `.gitignore` |
| `data/external/` | 外部数据集 | `.gitignore` |
| `outputs/` | 实验输出 | `.gitignore` |

## 五、配置管理

```yaml
# configs/default.yaml
data:
  batch_size: 32
  num_workers: 4
  train_path: data/processed/train.pkl

model:
  name: transformer
  hidden_size: 256
  num_layers: 6
  dropout: 0.1

training:
  epochs: 100
  learning_rate: 1e-4
  seed: 42
  device: cuda

logging:
  save_dir: outputs/checkpoints
  log_dir: outputs/logs
```

## 六、常用命令速查

```bash
# 创建项目
poetry new my-project
cd my-project

# 添加依赖
poetry add torch transformers numpy pandas

# 添加开发依赖
poetry add --group dev pytest black ruff

# 运行训练
python scripts/train.py --config configs/experiment_a.yaml

# 运行测试
poetry run pytest

# 代码格式化
poetry run black .
poetry run ruff check .
```
