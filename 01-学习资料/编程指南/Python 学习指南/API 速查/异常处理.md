# 异常处理

## 基础语法

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("不能除以零")
except Exception as e:
    print(f"其他错误：{e}")
else:
    print("没有异常时执行")
finally:
    print("总是执行")
```

## 常见异常类型

| 异常类型 | 说明 |
|---------|------|
| ValueError | 值错误 |
| TypeError | 类型错误 |
| IndexError | 索引越界 |
| KeyError | 字典键不存在 |
| FileNotFoundError | 文件不存在 |
| AttributeError | 属性不存在 |
| ImportError | 导入失败 |

## LeetCode 实战场景

### 1. 安全的字典访问

```python
def get_value_safe(d: dict, key: str, default=None):
    try:
        return d[key]
    except KeyError:
        return default

# 或使用 get 方法
value = d.get(key, default)
```

### 2. 整数转换

```python
def parse_int(s: str, default: int = 0) -> int:
    try:
        return int(s)
    except (ValueError, TypeError):
        return default
```

## 科研实战场景

### 1. 模型加载容错

```python
import torch

def load_model_safe(model_path: str, default_model=None):
    try:
        return torch.load(model_path)
    except FileNotFoundError:
        print(f"模型文件不存在：{model_path}")
        return default_model
    except RuntimeError as e:
        print(f"模型加载失败：{e}")
        return default_model
```

### 2. 实验重试机制

```python
import time

def train_with_retry(train_fn, max_retries=3):
    for attempt in range(max_retries):
        try:
            return train_fn()
        except RuntimeError as e:
            if attempt == max_retries - 1:
                raise
            print(f"训练失败，{attempt + 1}/{max_retries}, 重试中...")
            time.sleep(2 ** attempt)  # 指数退避
```

## 上下文管理器

```python
# 使用 with 语句
with open('file.txt', 'r') as f:
    content = f.read()
# 自动关闭文件

# 自定义上下文管理器 - 计时器
from contextlib import contextmanager
import time

@contextmanager
def timer(name: str):
    start = time.time()
    try:
        yield
    finally:
        end = time.time()
        print(f"{name} 耗时：{end - start:.2f}秒")

with timer("训练"):
    train()
```

## 最佳实践

```python
# 捕获具体异常
try:
    int(user_input)
except ValueError:
    print("请输入有效数字")

# 避免过度捕获
try:
    do_something()
except Exception as e:  # 不要使用空 except
    log_error(e)
    raise

# 使用 finally 清理资源
f = open('file.txt')
try:
    process(f)
finally:
    f.close()
```
