# 参考文献检索文档

> **说明**：本文档用于记录毕业论文中引用的所有参考文献及其检索直链，确保每一条文献真实存在、可追溯、可验证。
>
> **格式标准**：GB/T 7714-2015《信息与文献 参考文献著录规则》
>
> **填写要求**：
> - 每条文献必须在正文中以右上标形式引用
> - 直链优先使用知网（CNKI）、万方、DOI链接
> - 英文文献优先使用 DOI、Google Scholar、IEEE/ACM Digital Library 链接
> - 摘要中不标注参考文献

---

## 文献分类说明

| 类型代码 | 含义 | 示例 |
|:---:|:---|:---|
| [J] | 期刊论文 | 某某. 标题[J]. 期刊名, 年, 卷(期): 页码. |
| [D] | 学位论文 | 某某. 标题[D]. 学校, 年. |
| [M] | 专著/书籍 | 某某. 书名[M]. 出版地: 出版社, 年. |
| [C] | 会议论文 | 某某. 标题[C]//会议名. 地点, 年: 页码. |
| [EB/OL] | 网络资源 | 某某. 标题[EB/OL]. (发布日期)[访问日期]. URL. |
| [S] | 标准 | 标准号, 标准名称[S]. |

## 文献引用自查清单

- [ ] 每条文献都在正文中以右上标形式引用了
- [ ] 正文引用编号与文献列表序号一一对应
- [ ] 摘要中没有标注参考文献
- [ ] 没有捏造不存在的文献
- [ ] 每条文献都附有可访问的检索直链
- [ ] 文献格式符合 GB/T 7714 标准
- [ ] 文献总数达到 30 篇左右（不为凑数而乱加）
- [ ] 中英文文献比例合理
- [ ] 文献与正文引用位置的内容确实相关
- [ ] 网络资源类文献标注了访问日期
