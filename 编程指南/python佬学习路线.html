📋题目描述
实现 SSM 的核心方程：

连续形式：
h'(t) = A * h(t) + B * x(t)
y(t) = C * h(t) + D * x(t)

离散形式（Zero-Order Hold）：
h_t = A_bar * h_{t-1} + B_bar * x_t

其中：
A_bar = exp(Δ * A)
B_bar = (A_bar - I) * A^{-1} * B

I = I_0 * exp(-α * c * L)
